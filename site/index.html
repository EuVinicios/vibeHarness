O ciclo de vida, em 4 passos

Cada etapa tem um comando. Cada comando tem um propósito.

  1. 1

    Conexão em 1 clique

    vibe-harness install · mcp

    Configura as regras do seu projeto e conecta o servidor MCP automaticamente no Claude, Cursor, Windsurf, Copilot e mais.

  2. 2

    Antes do código

    vibe-harness prd · plan

    A IA gera sua especificação e monta a stack certa pra sua ideia — antes de escrever uma linha.

  3. 3

    Durante o código

    vibe-harness pack

    Limpa .env e chaves sensíveis antes de enviar contexto para o modelo. Seus segredos nunca viram prompt.

  4. 4

    Depois do código

    vibe-harness audit · doctor

    Avaliação de 0 a 100 em segurança e boas práticas, com correções sugeridas — e executadas pela própria IA.

Perguntas descomplicadas

Feito pra quem não domina Git ou terminal.

Preciso ser especialista em Git para usar?

Não. O CLI e a IA fazem o trabalho pesado: o VibeHarness guia merges, commits e deploys passo a passo, explicando o que está acontecendo a cada comando. Se você sabe o que é um repositório, sabe usar.

Funciona com qual IA?

Praticamente todas. Cursor, Claude Code, Windsurf, VS Code Copilot, Antigravity, Qwen e OpenCode — via arquivos de regras nativos ou protocolo MCP. Se a sua IA fala MCP, ela fala VibeHarness.

O que é MCP?

Model Context Protocol é um padrão aberto que conecta sua IA a ferramentas e contexto do seu projeto. Na prática: sua IA ganha superpoderes — ela mesma roda o harness, audita o código que gerou e corrige o que estiver errado.

Meus segredos (chaves, tokens) vão pro GitHub?

Nunca. O comando pack sanitiza o contexto antes de enviar ao modelo — .env e chaves viram placeholders. E o audit caça segredos acidentalmente commitados antes que causem estrago.

Quanto custa? Preciso de servidor?

O VibeHarness é open source (MIT) e roda 100% local, na sua máquina. O único custo continua sendo a sua IA favorita — a mesma que você já paga.
